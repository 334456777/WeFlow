## 技术致谢

以下开源项目为 WeFlow 与 [Echotrace](https://github.com/ycccccccy/echotrace) 的研发提供了至关重要的基石与灵感：

* **[密语 CipherTalk](https://github.com/ILoveBingLu/miyu)**：为项目起步阶段提供了不可或缺的核心基础框架
* **[WeChat-Channels-Video-File-Decryption](https://github.com/Evil0ctal/WeChat-Channels-Video-File-Decryption)**：为朋友圈视频的解密提供了重要的技术参考
* **[WxDatDecrypt](https://github.com/recarto404/WxDatDecrypt)**：为微信图片 DAT 文件的解密算法提供了宝贵的实现范例
* **[@H3CoF6](https://github.com/H3CoF6)**：为项目提供了Linux平台的密钥与功能适配支持
* **致敬曾经的先驱项目**：感谢曾在开源社区活跃、贡献过相关解析逻辑的所有开发者。哪怕你们的代码已经失效，项目已被迫关闭，但那些早期的探索路径，依然为我们提供了宝贵的经验
